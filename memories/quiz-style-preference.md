# Quiz Style Preference

When checking Erfan's understanding, for example in a teaching session, do not make the correct option always "A". He spotted a run of five questions where the answer was always the first option, which turns a comprehension check into position-spotting.

**Why:** a quiz that always puts the answer in the same slot tests pattern-matching, not understanding. He wants the check to actually probe whether he grasped the material.

**How to apply:** either ask open-ended questions and have him explain in his own words, or, if using multiple choice, randomize which option is correct and make the distractors genuinely plausible/hard rather than obviously wrong. Mix the two modes. Default toward open-ended "restate / explain why" prompts for load-bearing concepts.
