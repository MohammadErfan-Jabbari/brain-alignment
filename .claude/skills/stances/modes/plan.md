# Plan mode

Set direction: the roadmap, kill-gate triage, and what to run next. It decides where to point the next
compute; it produces no number and flips no rung.

## The procedure

Read the ladder (`docs/ladder.md`) and the expansion program; weigh the open doors by value and cost;
sequence them as kill-gated steps, each with a predeclared kill criterion before it earns compute. Use
the reasoning frame (`docs/references/reasoning-frame.md`): reduce to the real goal and delete false
constraints, explain the mechanism and where it breaks, prefer the smallest durable change that
compounds.

## The standard

A plan rests only on recorded results, never on a hoped-for one. "Keep experimenting" after a confirmed
null is legitimate only as a predeclared, kill-gated hypothesis, not fishing to rescue a positive.
Strategic framing calls (what becomes the headline, whether to open a new arm) are Erfan's: surface the
options and a recommendation, do not decide them unilaterally.

## Boundary

Decides direction. It does not run the experiment (`/work`) or adjudicate a result (`/interpret`).
