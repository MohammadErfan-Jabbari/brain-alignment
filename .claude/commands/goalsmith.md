You build the **`/goal` completion-condition** for a WORKING session on ONE item from `/orient` (passed as the argument). Know how the target works (docs: `code.claude.com/docs/en/goal`): Claude Code's `/goal` takes a condition that **is itself the directive** — it starts a turn immediately and, after every turn, a small fast evaluator model checks whether the condition holds, **judging only from what Claude has surfaced in the conversation** (it does not run commands or read files). It loops until met or `/goal clear`.

Therefore your output is **one string** that is: a directive + a **research-shaped completion condition Claude's own printed output can demonstrate** (resolve-or-root-cause, below) + a blocker escape. Hard constraints: **≤ 4000 characters** (the documented cap) and **a single line** (newlines can be truncated by `$ARGUMENTS` — keep it one line, clauses separated by `;` / `—`). It must **POINT to the item's PRD** — its `docs/experiments/E*.md` plus `expansion-program.md` §8 — and **never restate it**; the repo docs are complete and are the source of truth.

Output the goal string only. Do **not** start the work. WORKING sessions only — if the item is analysis-lane (reports R08–R14, manuscript, figures), stop and say so (D011).

Do this:

1. **Locate the item and its PRD.** Read `docs/ladder.md` ("Next session"), `docs/expansion-program.md` §8 (the Tier-1/2/3 run-list + the 5-control battery), `docs/idea-tree.md` (the node + the assumption it rests on), and the item's `docs/experiments/E*.md` — **that experiment doc IS the PRD** (design, deliverables, predeclared kill criterion). Optionally `mcp__gbrain__query` for prior work. If no item is given, propose the first open Tier-1 item and ask which. **If the item has no experiment doc, stop and say so — the PRD must exist first (offer to draft one), because the `/goal` string points to it.**

2. **Assemble ONE single-line `/goal` string, ≤ 4000 chars**, from these parts, instantiated for the item:
   - **Directive + PRD pointer** — "Execute the working session for <item> per its PRD `docs/experiments/E<nn>.md` + `expansion-program.md` §8: design → oracle-gate → run → panel-judge → record."
   - **The always-correct repeatable discipline (compressed, not the doc's detail)** — lock the estimand + predeclared kill criterion before running; apply only the *applicable* controls from the 5-control battery (name them; the rest N/A); strongest baseline at matched perplexity; ≥3 seeds; contiguous splits + nuisance baseline (anti-confound L003); **oracle-reviewer PASS before any compute**; ≤4 experiments parallel on the 4× L40S, `uv run`, subagent routing (opus=think/design/judge, sonnet=eng/doc-nav, haiku=mechanical, fable banned); after the run, the thinking panel (counter-argument + socratic-thinker + premortem-analyst + first-principles-grounder) + Codex code-critic, address every surviving objection (**panel-clean = every thinker's `PANEL-VERDICT` block is collected and a single `PANEL-CLEAN:YES` reconciles them; contradictions are resolved, not averaged**); gbrain-first; numbers only from runs; **no rung flip without Erfan**.
   - **Completion = the question is RESOLVED, not "the run finished" (research-shaped; surfaced in the conversation, since the evaluator only reads what Claude prints).** DONE only when EITHER **(A)** the experiment's hypothesis/expectation (from the PRD) is **confirmed** — verdict recorded with value ± CI, n, named test, panel-clean; OR **(B)** the result falls short of that expectation and the **cause is root-caused**: first hunt the code / pipeline / data / splits for an implementation cause (found → fix & re-run; benign → document), and if none exists, **ground the *why* in theory** (information / learning / deep-learning theory via `06-theory-grounding.md`) or **in the literature** (find the paper(s) that explain it). **Never close on a bare null** — the mechanism/proof must have **survived the thinking panel (counter-argument + first-principles-grounder) and been verified against the data**, not merely asserted (else the evaluator closes on a confabulation).
   - **Blocker escape (no fixed turn count)** — keep working until (A) or (B); **halt and surface to Erfan** only on a genuine blocker: an oracle HOLD, missing data/compute, a required scope/decision, or a theory question that is genuinely open. Never "stop after N turns."

3. **Print:** (a) one line — the item + its PRD file path; (b) the character count of the goal string; (c) the single-line `/goal` string in a code block, ready to paste. If over 4000 chars, trim the compressed-discipline clause first (it is the most recoverable from the docs). **Do not begin the work — the goal string is the deliverable.**
