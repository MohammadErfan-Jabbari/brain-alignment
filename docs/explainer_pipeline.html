How a text stream becomes a brain-alignment score

Both paths — the LLM and the brain — explained from input to verdict. No jargon left unexplained.

1 · The big picture (one paragraph)

We want to know: does a language model, when it reads a story, produce internal representations that predict what the human brain does while hearing the same story? To answer this cleanly we need two parallel pipelines that start from the same text:

The LM path — feed the text through the model, grab the activations from the middle layer, and resample them onto the brain's slow time grid.

The brain path — a human hears the same story in an fMRI scanner. The scanner measures blood-flow (BOLD signal) at every voxel every ~2 seconds (one TR).

Then we run a regression: can the LM activations predict the brain's BOLD, beyond the boring stuff (word length, speech rate, static word meaning)? The amount of extra variance the LM explains — unique R² — is the alignment score.

2 · The input (what goes in)

E002 — isolated sentences (the screen)

1000 individual sentences, each processed independently. No time axis. Fast to run. Used as a "lower bound" screen: if alignment doesn't show up here, it's nowhere.

E006 — naturalistic stories (the powered run)

~20 continuous stories (20 min of audio each). The subject hears the full narrative in the scanner. Realistic, but introduces temporal autocorrelation — needs extra machinery to keep honest.

The explainer below focuses on the E006 naturalistic path because it has all the complexity. The E002 path is the same thing minus the time steps.

3 · The LLM path blue lane

Step-by-step

1

Text → tokens → LM forward pass. The story text is tokenized and fed through the model in overlapping 256-token windows (stride 128) so every word gets as much left-context as possible. We read the hidden state at the middle layer (e.g. layer 7 of 12 for GPT-2, layer 12 of 24 for Qwen) — the sweet spot where alignment peaks in the literature.

2

Per-word vector. A word might span multiple sub-tokens. We take the hidden state at the last sub-token of each word. Result: one vector per word, dimension = d_model (768 for GPT-2, 896 for Qwen).

3

Lanczos resampling — word-rate → TR grid. Words arrive ~3–5 per second. The scanner takes one sample every ~2 s (1 TR). We need to "down-mix" the word vectors onto the TR grid. Lanczos is a windowed sinc filter — the same family used in audio resampling — it preserves frequency content without aliasing. After this step: one vector per TR instead of one per word.

4

FIR delays (1–4 TRs). Blood flow (BOLD) peaks ~5–8 s after the neural event that caused it (the hemodynamic response function, HRF). So a word heard at time t affects the BOLD reading most at t+3 to t+5 TR. Instead of modelling the exact HRF shape, we hand the ridge model 4 time-shifted copies of every feature (shifts of 1, 2, 3, 4 TRs) and let it find the best linear combination. This is the FIR (finite impulse response) trick.

5

Capacity-fair PCA (rank 100). The LM block is ~768–896 dimensions and the static-embedding block is 985 dimensions. A block with more columns wins variance by brute force even if its content is garbage. So we compress both down to exactly 100 principal components, fit on training data only. Now if the LM wins, it wins on content.

4 · The brain path orange lane

Step-by-step

1

Subject hears the story. While the story plays, the subject lies in an fMRI scanner. The scanner measures the BOLD (Blood-Oxygen-Level-Dependent) signal — a proxy for local neural firing. Every ~2 s it takes one full brain image.

2

95,556 voxels, but most are noise. A "voxel" is a 3D pixel of the brain (~2 mm³). UTS03 has 95,556 of them. Many voxels are white matter, cerebellum, or just noise. We need to pick the ones that reliably respond to speech.

3

Voxel selection — the noise ceiling trick (no double-dipping). One story ("wheretheressmoke") was repeated 10 times. We can ask: does voxel v give the same BOLD response each time it hears the same passage? If yes, it's reliable. We compute the split-half reliability (Spearman–Brown corrected) across the 10 repeats. Keep only voxels with reliability > 0.5. That leaves 11,442 reliable voxels.

Crucial: this reliability story is held entirely out of the encoding CV. We never score the model's predictions on it — we only use it to pick voxels. This prevents "double-dipping" (picking voxels you then score on = circular, inflated R²).

4

Result: BOLD matrix. Shape = (n_TRs × 11,442 voxels). Each row is one brain snapshot. This is our prediction target — what the model must explain.

fMRI scanner: one image every TR (~2 s)

5 · The nuisance stream green lane

What we refuse to give the LM credit for

If an LM "predicts" the brain only because faster speech = more neural activity, that's boring — it has nothing to do with language understanding. We build a set of low-level nuisance features and subtract their contribution first.

Low-level block (5-d, kept raw):

  • word-rate (words per TR)
  • phoneme-rate (phones per TR, from the TextGrid phone tier)
  • mean word-duration
  • word-length (chars and phonemes)
  • log word-frequency (static lexical scalar)

Static semantic block (985-d → PCA 100): eng1000 — a fixed vector per word, the word's meaning without context. Like a bag-of-words lookup table.

Not subtracted: surprisal. Surprisal is itself an LM output — subtracting it would erase the very thing we're testing. Log word-frequency (a static scalar) is subtracted and is distinct.

6 · How the two paths meet — the encoding model pink stage

With all streams prepared, we run a ridge regression — a linear model with L2 regularization — to predict each voxel's BOLD time series from the features. We do this in two designs, and the difference is the score.

Nuisance design: BOLD ~ [ low-level (5-d) + PCA(eng1000, 100-d) ] R²_nuisance = how well the boring stuff predicts the brain Full design: BOLD ~ [ low-level (5-d) + PCA(eng1000, 100-d) ] + PCA(LM, 100-d) R²_full = how well everything (boring + LM) predicts the brain Unique R² = R²_full − R²_nuisance = the variance the LM adds on TOP of the boring stuff = zero if LM is useless beyond length/rate/word-identity = positive if LM carries something the nuisance cannot

This unique R² is computed per-voxel, then averaged over the 11,442 reliable voxels. The cross-validation holds out whole stories — never individual TRs — so adjacent timepoints in the same story can't leak from train to test.

Story-grouped CV (5 folds, ~4 stories held out per fold):

  Fold 1: train on stories [2..20], test on stories [1..4]
  Fold 2: train on stories [5..20,1..4], test on stories [5..8]
  ...

  For each fold:
    fit ridge on nuisance design  →  R²_nuis (fold)
    fit ridge on full design         →  R²_full (fold)
    unique R² (fold) = R²_full − R²_nuis

  Average unique R² over folds + over 11,442 voxels
  → one number per model

7 · The two arms — trained vs untrained

Even after nuisance subtraction, an untrained (randomly-initialized) network of the same architecture can score a slightly positive unique R². Why? Because the random features still inherit the story's temporal structure — faster speech → more random activations → the nuisance can't fully remove it. So unique R² alone has no honest zero to measure against.

The fix: run the entire pipeline twice — once with the trained LM, once with a same-architecture model that was never trained (random weights, 3 seeds). The reported statistic is the gap:

gap = unique_R²(trained) − unique_R²(untrained) = [ R²_full(trained) − R²_nuis ] − [ R²_full(untrained) − R²_nuis ] = R²_full(trained) − R²_full(untrained) (the nuisance R² cancels — both arms use byte-identical nuisance) gap > 0 means: language training added something beyond architecture + nuisance + temporal structure. gap ≈ 0 means: the signal is an artifact — untrained features do just as well.

8 · What the math is actually saying (conditional mutual information)

Unique R² is not just a regression trick — it has a clean information-theoretic meaning. For three variables X, Y, Z, the conditional mutual information I(X ; Y | Z) is the dependence between X and Y that survives once you already know Z.

I(X ; Y | Z) = H(Y | Z) − H(Y | X, Z) H(Y | Z) = uncertainty about Y after knowing Z H(Y | X, Z) = uncertainty about Y after knowing both X and Z If knowing X on top of Z reduces uncertainty about Y → I(X;Y|Z) > 0 If X adds nothing once Z is known → I(X;Y|Z) = 0

In our setting:
X = LM middle-layer representation
Y = brain BOLD signal
Z = nuisance set (length, rate, static word meaning)

A2 claims: I(LM ; brain | nuisance) > 0 = the LM and the brain share information beyond what the boring stuff explains. Under the linear-Gaussian assumption, this is a monotone function of the squared partial correlation — and unique R² is exactly that partial r². So: unique R² > 0 ⟺ I(LM ; brain | nuisance) > 0

The "gap" framing (trained − untrained) further conditions out the shared temporal/architectural source, leaving only what language training contributed to this mutual information.

11 · Three design choices that keep the number honest

Contiguous splits (no shuffling)

Adjacent TRs in fMRI are strongly correlated. If you shuffle and then split, near-duplicates land on both sides of the train/test boundary — the model "sees" the test answers. Holding out whole stories removes this leak entirely.

Capacity-fair PCA (same rank, both blocks)

A 985-d block beats a 5-d block not by being smarter but by having more knobs. Compressing both to 100-d before the regression means the winner wins on content, not on dimensionality.

Voxel selection on held-out data

Picking voxels on the same data you score is circular — noise voxels get selected exactly when they randomly correlate with the model. Using a separate held-out story for reliability cuts this double-dipping.

Trained − untrained gap (not raw R²)

Even random features score positive on naturalistic timeseries (shared stimulus structure). The untrained arm provides the true zero, and the gap isolates what language training — not architecture — contributes.

Verdict (A2 / Q0): ✅ PASS — the alignment signal is real, beyond confounds.

A trained LM's middle layer predicts held-out brain activity significantly above an untrained same-architecture control, after the full nuisance subtraction and under contiguous story-level CV. The trained−untrained gap is +0.021 (GPT-2) / +0.028 (Qwen), with 95–99% of reliable voxels positive and tight bootstrap CIs excluding zero. The more capable model aligns more strongly — the expected quality ordering. This is the one load-bearing positive of the thesis. Real ≠ movable ≠ useful — those are answered in the reports that follow (R07–R14).
