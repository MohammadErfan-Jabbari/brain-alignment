# The Idea Tree — the full possibility space, by solution altitude

**What this is.** The forward-planning map of *every* idea this project could pursue, organized so the climb has a principled order. It is the complement of `[map.md](map.md)`: `map.md` records the **journey we have travelled** (history, the E-nodes that ran); this tree records the **whole space including the untravelled branches**, so "climb the highest untested layer" is a well-defined instruction. Canonical *status* still lives in `[ladder.md](ladder.md)` and the program state in `[expansion-program.md](expansion-program.md)`; when they disagree, the ladder wins and this gets fixed.

**Why "solution altitude" (the hierarchy choice).** Layers descend by *how fundamental the choice is*. The root is the thesis bet; L1 is the nature of the signal; L2 is what we *do* with it (the objective form); L3 is how we induce it (method); L4 is how we measure success (the metric); L5 are the concrete experiments. The higher the layer, the more a node *re-frames* the problem rather than tweaks a knob — and venue-worthy novelty lives in the high-altitude reframings, not the low-altitude knobs. So "start from the highest untested layer" = "attack the most fundamental untested reframing first," which is exactly where a new positive result (or a sharper paper) would come from. (Hierarchy to be panel-critiqued once the literature sweep adds nodes — P4.)

**Status legend:** ✅ tested-positive · 🟡 partial · ❌ tested-negative (null/kill) · ⬜ untested · ◻️ untested+low-prior (argued-shut, not measured).

## The climb queue (RE-SEQUENCED after the strategy premortem, S22)

The premortem (opus, S22; verified against the ladder) overturned the provisional order. The corrections that held:

- **Run the load-bearing experiment BEFORE the scaffolding.** The full sweep→tree→climb-as-prerequisite was procrastination — lit-scout already returned what the sweep was for ("no new positive to discover"). The scout tooling is a reusable asset (let it finish), but the climb does **not** block on a 100k-paper sweep; *focused* lit checks ground each node.
- **Honest venue bar:** this body of work (a robust null in the fMRI/encoding-R²/distillation paradigm) realistically tops out at a **strong workshop/Findings paper + an excellent thesis**. A top-10 **main-track** acceptance is *conditional on a genuinely new positive*, and the only node that can mechanically produce one is **T1.3**. Tracked honestly; Erfan adjudicates the ambition.

Compute budget = 4× L40S → up to 4 nodes in flight. Revised order:

1. **TA.4 — Path-A external demonstration, RE-SCOPED as a multi-target PROTOCOL (not a one-target takedown).** Run the load-bearing test first. Contribution = "*matched-perplexity + permuted-twin is the missing control that re-prices brain-guided-training claims*," demonstrated across (i) our own E005→E008 averaging collapse, (ii) Negi'25 (text-LM, the **encoding** half, attack-on-paper), (iii) Moussa'25 (speech, **if** the feasibility gate says clone-and-run). **Write the one-paragraph contribution claim BEFORE touching GPUs** (premortem #1). *Substrate caveat (premortem):* Moussa is speech + its headline is generalization/efficiency, not a raw alignment gain — a single speech target from a text-LM thesis is incoherent and Findings-tier; the protocol framing across our-own + text + speech is what could lift it. *Honest tier: Findings/workshop unless the multi-target protocol genuinely lands.* **Feasibility = GO-WITH-CAVEATS (S22):** repos cloned, fMRI present, matched-arm is ~50-100 lines; blockers are data-logistics (story audio + grids from an Antonello Box link, liveness unconfirmed) + the permuted arm must be reimplemented (it is dead code in the NeurIPS repo). Data-acquisition launched.
2. **T1.3 — surprisal-residualized cognitive-signal training (the keystone). RESOLVED → CLEAN NULL on cognition (v5, 2026-06-18).** Full chain ran to completion (G0/G1 PASS → metric fixed after G2 caught a biased metric → Codex caught a code bug → n=10 → v4 looked like a positive → panel + a phase-randomized shape-matched control killed it). **Final verdict:** (a) surprisal-orthogonality NULL (raw≈residual); (b) generic word-aligned aux-regularization dominates (~430 AULC gap); (c) the real RT edge over learnability-matched controls is **signal SHAPE, not cognition** — a content-free phase-randomized twin (RT's autocorrelation lag-1 0.62 + kurtosis 13) TIES the residual (172.1 vs 177.4). Human reading time carries no cognition-specific *trainable* structure here beyond its statistical shape. **A clean cross-modal NEGATIVE** extending the fMRI null (E008) to behavioral data with the mechanism pinned — strengthens the Path-A negative paper. The main-track positive did NOT materialize. → E021. No rung flip. The lit-gate's decisive finding: reading-times/N400 are *extremely well predicted by LM surprisal*, so naive regularization is **circular** (= the fMRI-null mechanism in a new coat; BabyLM showed cognitive aux-objectives ≈ randomized-order nulls). The **only** viable positive mechanism = the **residual of the cognitive signal after the model's own surprisal is regressed out** (the Merlin-Toneva "beyond-next-word" move applied to behavior/EEG). EEG-*guided training* (vs decoding) is genuinely unscooped; behavioral is partly scooped (Deng ACL'24: raw gaze, BERT, in-dist GLUE, no residualization/matched-ppl). **Why GO on a weak prior:** cheap (small decoder LM + ZuCo), clean predeclared kill criterion, and **dual-publishable** — a null generalizes our fMRI negative across fMRI+behavioral+EEG (stronger, main-track-shaped), a surviving residual arm is the new positive. → **E021** (designed next, oracle-gated before compute).
