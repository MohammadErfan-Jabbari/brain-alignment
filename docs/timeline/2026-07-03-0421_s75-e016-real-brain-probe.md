## Summary

Added a post-hoc real-brain alignment evaluator for saved E016-style students. The new helper, [`../../scripts/e016_eval_saved_student_alignment.py`](../../scripts/e016_eval_saved_student_alignment.py), reads an E016 run JSON, loads rows with `model_artifact_dir`, and scores each saved student on Tuckute 2024 with the E003 contiguous-CV nuisance-subtracted protocol. This gives the positive branch an executable path from saved synthetic-target/control students to a real-brain alignment diagnostic.

This is infrastructure only. The evaluator output is a diagnostic input to `/interpret`; it does not establish an E016 verdict or a real-brain paper claim by itself.
