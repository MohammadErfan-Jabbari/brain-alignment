### 2. Architecture sections added to E002 and E006

Both experiment files gained a "System architecture" section: Mermaid flowchart + stage-by-stage walkthrough. Key design rationale now documented:

- **Last-sub-token:** causal LM — the last sub-token has attended over all word pieces; standard in the field (Schrimpf 2021, Toneva 2022, Kauf 2024). Mean-pooling over sub-tokens smears context-sensitive information.
- **Lanczos resampling:** windowed sinc filter, word-rate → TR-rate. No frequency artifacts; standard in the deep-fMRI-dataset pipeline.
- **FIR delays (1–4 TRs):** model hemodynamic lag ~5–8 s without assuming a fixed kernel shape.
- **Capacity-fair PCA (rank 50/100):** prevents dimension-count wins between the LM block and the static embedding block.
